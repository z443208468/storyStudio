## Root and minimal correction

The old CLI selected the registered accounting/admission route from its output
directory alone. A legacy output with registered input or critique could reach
the native component with no parent and no RunAccount.

critique and output ownership. Any registered participant requires the parent
and a registered output in the same project; the input must belong to that parent
Run and the critique to that project. The CLI checks these bindings before Key
access, authorization/account selection, native execution, slot or reservation.
The lower component independently repeats the check and rejects an account
without registered output ownership. No authorization function was weakened.
True legacy input plus legacy output retains its prior accounting route.

change. This remains ATOM-05; no later Atom, real story, migration or cutover is
